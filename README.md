# 請來體驗看看——當醫院資訊人員的一天

模擬遊戲：醫院資訊單位人員的一天。角色有剛到醫院的新人、值班人員、專責工程師（網路／資安／資料庫／系統／程式／PACS）、主任。給新人練判斷與底線，給主管看人力配置的差異。單一 HTML，無後端。

- **首頁**：`index.html`。左邊進入遊戲，右邊專業訓練。
- **3D 版遊戲**：`game/index.html`。Three.js 與字型已內嵌，院內電腦不用連外網也能玩。
- **2D 像素版遊戲**：`2d/index.html`。電腦比較舊、3D 跑不動時用這個。
- **專業訓練**：`train/index.html`。資訊各領域的闖關題庫（異常排除、硬體、軟體、網路、資安、Windows、Linux、資料庫、醫療資訊、法規治理），不限醫院情境。題庫在 `src/train.html` 的 `DOMAINS`，每個領域 `lv` 陣列放三關，每關一個題目陣列；每題第一個選項是正確答案，出題時會打亂。

兩個版本用同一套事件、做法選單、因果與評分；3D 版的地圖較大，走路速度已校準成跟 2D 花一樣的遊戲時間。

## 部署到 GitHub Pages
1. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`
2. 首頁：`https://<帳號>.github.io/it-duty-day/`；遊戲在 `game/`、`2d/`，訓練在 `train/`

## 3D 版功能
- 開場是院區外觀，選醫院大小後大樓數會跟著變（1／2／3／5 棟）
- 各單位照實際格局：門診診間、開放式病房與護理站、加護病房雙層門、開刀房更衣區、急診分區、影像鉛牆機房、核醫、內視鏡、心導管等
- 工單會標在實際設備上（讀卡機、印表機、AP、電腦推車、工作站…）
- 結算可以列印檢討單、下載檢討單（網頁檔）、下載 CSV，給帶新人的學長對照討論

## 原始檔與打包
- `src/game.html`：2D 版原始檔，事件、做法選單、評分都在這裡（兩版共用）
- `src/head3d.html`、`src/r3d.js`、`src/patch_logic.py`：3D 版的畫面、場景與地圖調整
- `python3 src/build.py`：重新產生 `index.html`（首頁）、`game/index.html`（3D）、`2d/index.html`（2D）、`train/index.html`（訓練）。首頁原始檔是 `src/landing.html`。改完 `src/` 一定要跑一次
- `tests/`：檢查腳本（需要 Node 與 Playwright）
  - `check-menus.js`：每套做法選單的步驟接得起來、都有最佳答案
  - `check-answer-length.js`：最佳答案是不是又變成最長的那個
  - `check-floors-3d.js`：3D 每層樓都走得到
  - `autoplay-3d.js duty:day:1`：自動玩完一班，確認沒有錯誤
  - `export-review.js 輸出檔.html`：匯出全部做法選單的對照表，給熟流程的人核對

## 改內容（兩版共用的資料）
- 事件腳本：`EV`（白班）、`EV_EVE`、`EV_NIGHT`、`EV_HOL`、`SPEC_EV`（各專責）
- 做法選單：`PROC`（每類問題的決策樹）、`DEEPEN` / `DEEPEN2`（補充選項）。選項在遊戲裡會打亂順序
- 電話教：`GUIDE`；釐清題：`TRIAGE`；後果：`CONSEQ`；壞結局：`ENDINGS`
- 樓層與單位：`BLUEPRINT`（四個難度）、`UNIT`、`TPL`（額外單位的工單模板）
- 小七／美食街菜單：`MENU`；專長與特質：`SKILLS`、`TRAITS`
- 3D 版另外有：工單對應設備的規則 `DEVRULES`

做法選單的答案是遊戲預設，請以院內 SOP 為準。

## 專業訓練（資訊職訓中心）

- `train/`：3D 職訓中心（中庭＋九間主題實習教室），`train/2d/`：2D 地圖版，進度共用（localStorage `ittrain_v1`）。
- 原始檔：`src/train.html`（題庫、課程、考試流程、2D 地圖）＋ `src/village3d.js`（3D 場景）。
- 課程在 `COURSES`：一門課一位師傅，`src` 指到 `DOMAINS` 題庫，每次抽 8 題。四級：初級、中級、高級、專家；某一級錯一題以內就拿到該級稱號。
- 九門基礎課四級題目都有了（共 304 題）。用語和法規以台灣為準。
- 進階專科在 `ADV`：九科各一位主任，`need` 是要先考到中級的基礎課。3D 版從中庭搭電梯到進階專科大樓。每科四級題目都有了。全部共 576 題。
- 專業訓練的定位是「資訊」這門專業，不針對醫院：題目用一般公司的情境，不放醫療資訊專科。法規以台灣現行法為準（資通安全管理法 2025 年修正、個資法 2025 年修正）。
- 進階課程分六條專業路線（`track`），共 13 科；`need` 可寫成 `[課程, 級別]` 指定先修到哪一級。對話框可勾「練習模式」（不扣命、不存檔）。每題都有 `t`（主題），結算時會列出答錯的主題。
- `node tests/export-train-csv.js 檔名.csv` 匯出全部題目，含路線、主題和待填的審核欄位。
